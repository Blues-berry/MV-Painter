# Prior art and novelty assessment

## 评估问题

候选差异不是“对几何尺度做了动态控制”，因为对扩散层、时间步或条件强度做调度已有直接先例。需要证明的差异应当是：使用真实网格/相机对应下、从第一次生成与烘焙得到的推理时反馈，确定性地重新分配六视角、必要时分配到采样阶段的几何残差预算；该动作在同预算和同计算量对照下改善未见视角烘焙质量。

目前没有得到这条完整方法链。本次工作只建立候选张量接口，没有验证上述反馈策略。

## 逐项对照

| 工作 | 输入与目标 | 控制位置 / 3D对应 | UV或参考反馈 | 是否动态改几何残差 | 训练/推理成本 | 与候选的关系 |
|---|---|---|---|---|---|---|
| [Scheduled Style Injection](https://arxiv.org/abs/2605.26538) | 内容图、风格图、ControlNet 深度；改善风格与内容的 Pareto 权衡 | 在去噪层/时间步调度 StyleID 的 γ 与 ControlNet 几何条件强度；未使用网格表面对应 | 无 UV 烘焙反馈 | 不是按表面反馈逐视角分配，但明确说明固定/分阶段控制已是已知方向 | 免训练；多配置研究，推理仍是常规扩散调用 | 静态时间/层调度是强基线，不能作为新颖性本身 |
| [Adaptive Projected Guidance](https://arxiv.org/abs/2410.02416) | 文本条件生成，降低高 CFG 的过饱和和伪影 | 将 guidance 更新分解并投影/裁剪到特定方向；没有真实网格或视角 tile 对应 | 无 | 投影的是引导向量，不是几何 Adapter 残差预算 | 免训练，推理时修改 guidance 更新 | “投影”一词或向量重分配不足以构成区别；目标量与反馈域不同 |
| [TexFusion](https://arxiv.org/abs/2310.13772) | 文本到 3D 纹理，多视图扩散结果融合到共享纹理 | 由网格 UV/相机映射图像空间与共享 UV 表示 | 是；去噪中将多视角结果投影到共享纹理 | 以共享 UV 状态融合解决一致性，不是调整每个视角的几何残差 | 无专门训练；以多视角扩散和共享潜变量优化为代价 | 已有“扩散—UV 投影—多视角反馈”机制，概念上高度相关 |
| [MD-ProjTex](https://arxiv.org/abs/2504.02762) | 免训练多视图 3D 纹理生成 | 用表面法线、可见性和视角选择，将多视图噪声预测投影/融合到共同 UV 更新 | 是；每个去噪阶段使用跨视角/表面投影反馈 | 反馈作用在共识噪声/UV 更新，不是候选的每视角几何残差预算 | 免训练，但需多视图预测与反复融合，具体调用数随配置而变 | 最接近的机制先例；仅把其表面误差换成尺度调节可能只是已知模块组合 |
| [DirectUV](https://arxiv.org/abs/2609.34651) | 参考图条件的直接 UV 纹理生成 | 训练的 UV 扩散模型使用表面位置/UV 到 3D 的位置编码 | 输入有参考图和 UV 表示，但不是本候选式后烘焙控制环 | 不通过逐视角 Adapter 残差预算控制 | 需要训练/预训练的专用模型；一次模型生成链 | 说明表面感知 UV 建模已经是近期方向；任务和架构不同 |
| [Im2SurfTex](https://arxiv.org/abs/2502.14006) | 多视图图像重建/合成表面纹理 | 训练的注意力反投影使用 3D 位置、法线和测地信息映射到 UV | 使用多视图几何对应；非生成后反馈调节 | 不 | 训练好的前馈网络，一次推理 | 表面对应反投影不是新颖点；候选若只有这种对应也不足 |
| [RomanTex](https://openaccess.thecvf.com/content/ICCV2025/html/Feng_RomanTex_Decoupling_3D-aware_Rotary_Positional_Embedded_Multi-Attention_Network_for_Texture_Synthesis_ICCV_2025_paper.html) | 3D 感知纹理合成，处理参考与几何条件的冲突 | 3D-aware RoPE、多注意力，并有几何相关 CFG；具体算子层面 | 使用几何/参考条件，但本次未能读取可检索的全文公式来核对反馈闭环 | 不能据现有材料断言与候选执行了相同方向投影或每视角预算重分配 | 专用模型/架构路径；细节须由原文全文确认 | 概念相邻。方向投影等价性未核实，故不作“已被完全覆盖”结论，也不能宣称新颖性已排除 |
| [GeoDiffuser](https://doi.org/10.1016/j.neucom.2026.133690) | 多模态几何、参考、文本条件下的纹理/形状生成 | 可见的出版信息摘要指向对应关系注意力和 2D↔3D 闭环反馈 | 高概念重叠；发布方全文本次不可访问 | 具体反馈变量和动作未从全文核实 | 需核对完整论文与实现 | 作为待查高重叠先例；全文公式和代码比对未完成 |
| [MultiDiffusion](https://arxiv.org/abs/2302.08113) | 把多个扩散生成过程约束到共享输出 | 约束优化/共识融合；无真实网格 UV 的专用几何残差控制 | 可有跨视图共享约束，不等于真实表面反馈 | 否 | 每轮需处理多个去噪过程 | 通用多视图共识背景先例，强调等成本比较的必要性 |

## 对先例的谨慎解释

- Scheduled Style Injection 已表明“按层/时间步调节条件强度”是可行且免训练的常见研究路线。因此只选择一条更好的固定 TCAS/C3 profile 不构成新方法。
- TexFusion 和 MD-ProjTex 已把多视角扩散输出投到共享 UV/表面并在生成过程中反馈。BAVGC 若做成 UV 误差驱动的尺度手工规则，需要证明动作不是这些融合方法与已知调度的简单拼接。
- RomanTex 的论文题目和可见摘要表明其用 3D-aware attention 与几何相关 guidance 处理条件冲突；本次官方页面读取失败，不能声称它与每视角残差重分配完全相同。必须获得论文全文后逐式核对。
- GeoDiffuser 的发行方页面本次无法读取全文。闭环反馈带来高概念重叠，但具体算子尚未验证。这里保留为新颖性待核查项，而不是既定结论。

## 仍可能成立的差异（待证）

唯一可考虑的差异是：在冻结生成器上，利用可见参考误差与经遮挡/覆盖校准的表面冲突，输出可审计的六视角 residual scale 调整；在 Native cap 内保持总尺度预算；以相同种子重生成；再用未见视角真实烘焙质量和等计算量无反馈选择基线检验增益。

本次没有选出有效 UV 误差信号，也没有确定每个误差应增大还是减小哪一视角的尺度。故这仍是研究假设，不是已建立的新颖贡献。
