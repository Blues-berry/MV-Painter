# Equal-cost baseline archive map

This folder contains byte-preserving copies of the additional Fixed Mean seed-43 run and its bake/render evaluation. The original execution directory was `/4T/tmp/MV-Painter-local-excluded-20261013/1014_counterfactual_control_research/`; the archived copies below are included in `SOURCE_HASH_MANIFEST.json` and their hashes are checked against the execution files.

## Successful run

- `generation/`: six seed-43 B0 panels, residual-dose traces, input hashes, per-object metrics, per-view metrics and run manifest.
- `bake/BAKE_INPUT_HANDOFF.json`: custom handoff with remapped tile paths and the additional candidate.
- `bake/cpu_bake_v3/`: 18 records for GT, Fixed Mean seed42 identity replay, and Fixed Mean seed43; includes PNG textures, coverage, textured GLBs and metadata.
- `bake/native_egl_unseen/`: 198 512×512 EGL views, render manifest, object/per-view metrics and evaluator report.
- `bake/BAKE_ATTEMPT_02.log`: successful canonical UV bake run log.
- `bake/NATIVE_EGL.log` and `bake/EVALUATION.log`: successful render and scoring logs.

## Retained failed attempts

- `failures/ATTEMPT_01_FAILED_PREGEN.log`: first launch stopped before inference because a relative pretrained-model path was resolved from the wrong working directory.
- `failures/ATTEMPT_02_FAILED_DATASET.log.gz`: complete, losslessly compressed log of the dataset-root mistake; no images were generated by that attempt.
- `failures/BAKE_ATTEMPT_01_FAILED_PATH.log`: first bake stopped when source tile paths referenced the workspace mirror instead of the isolated artifact location.
- `failures/BAKE_ATTEMPT_01_PARTIAL_OUTPUT/`: the partial GT/B0 bake files produced before that path error; kept separate from successful outputs.

The successful reruns used the original recorded data root, corrected path mapping, and the unchanged frozen UV baker and EGL renderer. The failures were setup/path issues, not quality filtering; they are preserved for audit.
