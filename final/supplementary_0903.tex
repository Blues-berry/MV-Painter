\section*{S1. Cohort, conditions, and analysis protocol}

The primary Fresh C run contains 300 frozen objects and four conditions: no adapter, global fixed low scale (GFL, requested scale 1.25), global fixed high scale (GFH, requested scale 2.50), and C3. The separate Fresh C addendum compares C3 with layer-wise low--low--high (LLH) and generic linear. The reviewer-requested C3--GFH contrast is a post-hoc analysis within the same frozen Fresh C cohort. The separate Fresh B supporting sensitivity contains 150 disjoint objects and is also post hoc. Cohorts and contrast families are not pooled, meta-averaged, or treated as independent replications.

Each Fresh C object contributes one paired value per endpoint after averaging its six target views. The object is the inferential unit. The primary and addendum paired estimates use 10{,}000 object-bootstrap resamples and two-sided percentile 95\% confidence intervals. The C3--GFH audits use the deterministic RNG seed 20261002; no p-values are used to establish equivalence or non-inferiority. For PSNR and SSIM, higher values are favorable; for LPIPS, lower values are favorable. The Fresh C C3--GFH audit verified 300 unique UIDs per condition, exact UID and input-identity matches, matched per-object seed policy, one runner, one checkpoint, and one metric implementation. Its classification is \texttt{REVIEWER\_REQUESTED\_POST\_HOC\_AUDIT}.

The raw-output, cohort-manifest, checkpoint, runner, metric, and analysis-script SHA-256 values are recorded in the machine-readable source-integrity and numerical-authority manifests accompanying this revision. Those hashes identify the recorded inputs and implementation; they do not, by themselves, establish a clean-checkout rebuild of the original image-generation payload.

\section*{S6. Boundary-test summary}

The MVDiffusion panel contains 75 objects and uses the unchanged compatibility base \texttt{sd21\_depth\_compat} because the official depth weights were unavailable. For L-LLH minus G-FL, mean PSNR is $-0.4538$ dB (95\% CI $[-0.7521,-0.1605]$) and mean FG-LPIPS is $-0.0027$ (95\% CI $[-0.0076,+0.0018]$). This is interface-specific, mixed boundary evidence. The MV-Adapter panel contains 98 objects after one frozen source-mesh exclusion. Its interaction reanalysis was exploratory and no metric survived Holm correction. Neither result establishes universal transfer, an architecture-level cause, or a confirmatory no-interaction finding.
