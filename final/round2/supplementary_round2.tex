\section{S7. FAC controlled re-examination}

FAC is a separate learned extension protocol, not a main contribution. The
base model, VAE, and adapter are frozen; only lightweight controllers are
trained on a disjoint training pool. Under the paired re-examination, no
trained configuration improves the training-free schedule. The paired
foreground-PSNR deficits range from $-1.10$ to $-2.94$ dB, while the
untrained exact-envelope control has $\Delta=-0.18$ dB with 95\% CI
$[-0.42,+0.05]$. The interval crossing zero is not an equivalence claim.
The complete dose--response records are retained as a negative extension
audit; the earlier positive FAC comparison used a different protocol and is
not used in the revised claims.

\section{S8. Bounded residual-budget controller pilot}

We tested one residual-budget controller extension (TRB-TCAS) on the
24-object clean-v2 development probe before considering any holdout run. The
run used 50 denoising steps, six unique target views, seed 42, shared
per-object batches and initial latents, and fixed-low, C3/LHL, HLL and LLH
controls. FG-LPIPS was the pre-specified primary metric. TRB obtained
FG-LPIPS $0.1349$, compared with $0.1404$ for fixed-low and $0.1336$ for C3;
its PSNR was $22.700$ dB, compared with $22.261$ dB for fixed-low and
$22.971$ dB for C3. The calibration pass approximately doubled the mean
controller time per object (12.342 s versus 6.075 s for C3). Since TRB did
not improve the existing C3 schedule and added cost, the branch was stopped
before a holdout run. These results are retained as a negative method-iteration
record, not as a claim about the main TCAS method.

The machine-readable output is
\texttt{TRB\_DEV24\_GATE\_20260929.md} and the independent pilot
\texttt{pilot\_results.json}. The pilot does not justify relabelling LLH as a
CAI-selected schedule: LLH is reported only as a fixed schedule control.

\paragraph{Runner sensitivity of the probe.} The reference conditioning image
undergoes a random stretch/compress (scale 0.5--1.5$\times$) inside the
dataset loader; targets, masks, depths, and view order are deterministic.
Consequently all methods within one run are strictly paired, but absolute
values are not comparable across separate runner invocations. A second,
independent shared-input probe run of the same schedules (conducted for the
complete factorial below) reproduces the LLH-over-LHL direction but changes
the sign of the small LHL-vs-constant-low difference; we therefore claim only
directions that hold in both runs and on the holdout.
