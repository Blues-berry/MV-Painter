## Paired development comparisons

- TRB − C3 FG-LPIPS: `+0.001302`, approximate paired 95% t interval
  `[-0.000018, 0.002622]`, 10/24 wins. Since lower is better, this is not a
  practical improvement; PSNR is `−0.2711 dB` and FG-MAE is `+0.0200`.
- TRB − fixed-low FG-LPIPS: `−0.005508`, interval
  `[-0.007904, −0.003113]`, 20/24 wins. This shows the controller can improve
  the conservative baseline, but it does not beat the existing C3 schedule.
- LLH − C3 FG-LPIPS: `−0.010508`, interval
  `[-0.013333, −0.007683]`, 23/24 wins; LLH also improves PSNR by `1.3982 dB`.
  This is a schedule comparison, not evidence that CAI selected LLH.

## Gate decision

**TRB-TCAS is stopped and is not merged into the manuscript.** It has no
stable practical gain over the existing C3 baseline on the pre-specified
development set, and calibration cost is substantial. No strict-276 TRB
holdout run will be launched. The result is retained as an internal negative
method-iteration record and supports a narrower TCAS contribution: stage
placement and trade-off analysis, not an input-conditioned controller claim.
