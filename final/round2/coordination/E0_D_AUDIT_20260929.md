# E0-D 只读审计报告

审计日期：2026-09-29 UTC  
范围：仅核验已有 D1/D2/D3 证据，不启动 GPU，不运行模型、Blender 或指标重算，不修改实验产物、论文、指标实现或既有文件。

## 总判定

**总体：WITH_LIMITATIONS。**

- **证据链与产物完整性：PASS。** 12 个 Exact GLB、48 个对象—条件记录和 528 个 unseen-view 记录均可追溯；source/unseen 映射、文件存在性和 Exact GLB SHA-256 配对通过。
- **R1“相对 fixed-low 改善真实 3D 质量”：FAIL。** 当前 12-object diagnostic bake 不支持 C3/TCAS 在完整物体、纹理忠实度或生成式 3D 输出上优于 fixed-low；反而显示明显的 generated-source color/source-fusion 限制。
- **论文使用资格：WITH_LIMITATIONS。** 可以作为固定、分层的 Exact-GLB 实现/案例证据和失败边界，不能作为 276/300-object 的总体 3D 优势证据。

## 3. Seam、coverage 分母与缺测处理

依据 `geotex/cpu_texture_bake.py`、`geotex/evaluate_cpu_bakes.py` 以及已有 CSV/JSON：

- `gt_coverage` 和 `render_coverage` 是每个 unseen view 中 alpha `>0.5` 的像素数除以全部 `512×512` 像素；对象级值是 11 个 unseen view 的算术平均，不是按前景像素数加权。
- `texture_coverage` 是 `texture_weight > 1e-8` 的 texel 数除以全部 `1024×1024` texel，表示 **raw coverage、inpaint 前** 的覆盖率。
- `texture_coverage_after_inpaint` 和 `inpainted_fraction` 仍以全部 `1024×1024` texel 为分母；前者是 8 次 explicit 4-neighbor UV propagation 后的可用 texel 比例，后者是新增填充 texel 占全部纹理的比例。raw coverage 没有被覆盖掉。
- `uv_seam_discontinuity` 是 seam-pair 上两侧采样颜色欧氏差的均值，分母在实现上是 `len(seam_pairs)`；如果没有 seam pair，函数返回 NaN。现有 metadata/CSV 只保存最终 scalar，没有保存 seam-pair 数，因此数值分母无法从结果包独立复核。所有已发布行显示为 `0.0`，不能据此写成“无 UV seam”。
- 已发布的非 DISTS 数值字段均为有限值，没有把缺测填成 0。DISTS 状态明确为 `unavailable: ModuleNotFoundError("No module named 'DISTS_pytorch'")`；CSV 的 DISTS 列为空，应按 unavailable 处理，不应称为 NA=0 或 DISTS 通过。

具有代表性的 coverage 限制如下（所有方法对同一对象共享同一几何/visibility coverage）：

| 对象 | raw texture coverage | after inpaint | inpainted fraction | 解释 |
|---|---:|---:|---:|---|
| `obj_0078` | 0.0328 | 0.3130 | 0.2802 | 极低 raw coverage |
| `obj_0082` | 0.0286 | 0.5237 | 0.4951 | 极低 raw coverage，近半纹理由传播填充 |
| `obj_0013` | 0.1169 | 0.3348 | 0.2179 | 高复杂度对象，raw coverage 较低 |
| `obj_0048` | 0.1547 | 0.9988 | 0.8441 | 最终覆盖率主要来自 inpainting，不能等同于观测到的纹理覆盖 |

## 4. GT-to-GT smoke 与 generated bake 的边界

`cpu_bake_smoke_final` 才包含 `gt` 条件，范围只有 `obj_0015` 和 `obj_0013` 两个对象、5 个条件、110 个 unseen-view 行；`gt_to_gt_sanity_rows` 为 2。已有报告给出的 masked PSNR / silhouette IoU 为：

- `obj_0015`：42.3589 dB / 0.9999167；
- `obj_0013`：30.8646 dB / 0.9996277。

这支持 camera、UV、visibility、导出/重导入和软件 raster path 的 smoke sanity，不支持生成纹理的颜色忠实度或方法优势。`cpu_bake_12` 实际只包含四个 generated methods，当前 `UNSEEN_METRICS_SUMMARY.json` 的 `gt_to_gt_sanity_rows` 为 0；`BAKE_12_VALIDATION_AUDIT.md` 仍以“`gt_to_gt_sanity_rows: 12` bookkeeping”描述，两者存在记录不一致。无论取哪一处，已有文件都明确说明：12-object 正式 batch 没有 12 个 GT bake，GT-to-GT 证据只有上述两对象 smoke。

generated bake 的 unseen renderer 是 unlit texture lookup，目标是隔离纹理/几何/相机行为，不是最终 Cycles photometric relighting。已有 D 报告和抽查指出 generated render 存在明显 cross-view color/contour/source-fusion inconsistency；这属于 generated appearance limitation，而不是由 GT smoke 证明已经解决。

## 5. `obj_0048` exporter 限制

`BAKE_12_VALIDATION_AUDIT.md` 记录：Blender 4.2.4 的 glTF round-trip 对 `obj_0048` 的若干 mesh components 做了 vertex reindex/deduplication。polygon count、UV loop 数据、UV 语义和渲染 bake 路径保持；部分 vertex count 与 world bounding box 在 exporter precision 下变化。因此：

- 原始输入 GLB bytes 未被修改；
- 可写为 semantic geometry/UV preservation for the rendered bake；
- 不可写为 byte-identical mesh export 或逐顶点字节级保持。

该对象同时采用 reversed view mapping，且 raw coverage 只有 0.1547、inpainted fraction 为 0.8441，应作为限制案例而不是完整纹理成功案例。

## 6. R1 实际 3D 质量问题是否被回答

结论是 **FAIL（针对“C3 优于 competitive fixed-low”这一要求）**，但结果可用于支持负面边界和失败分析。

已有 `CPU_BAKE_PHASE2_REPORT.md` 的 12-object 非加权均值为：

| method | masked PSNR ↑ | CIEDE2000 ↓ | FG-LPIPS ↓ | raw texture coverage |
|---|---:|---:|---:|---:|
| no_adapter | 11.8245 | 18.2004 | 0.1563 | 0.1574 |
| fixed_low | 6.0008 | 48.6233 | 0.1988 | 0.1574 |
| c3 | 5.6382 | 51.1835 | 0.2009 | 0.1574 |

对已有 `UNSEEN_OBJECT_METRICS.csv` 做对象内配对方向检查：C3 相对 fixed-low 在 masked PSNR 上为 0/12 胜、CIEDE2000 为 0/12 胜、FG-LPIPS 仅 2/12 胜；相对 no-adapter 三项均为 0/12 胜。fixed-high 上 C3 的颜色误差较好，但这不能转化为相对 fixed-low 的优势结论。silhouette IoU 与 coverage 主要由共享几何、相机和 visibility 决定，不能单独证明生成纹理忠实度。

因此，D 证据能够回答“真实 Exact-GLB bake/unseen path 是否存在、如何失败、是否可追溯”，不能回答“TCAS/C3 已改善完整物体和纹理忠实度”。在当前证据下，R1 的正向质量主张不能保留。

## 7. 失败/限制案例清单

1. **方法质量失败边界：** C3 未在该 diagnostic cohort 上胜过 fixed-low；no-adapter 反而在三项主要 unseen 颜色指标上更好。
2. **覆盖不足：** `obj_0078`、`obj_0082` raw coverage 极低；`obj_0048` 的 84.41% 全纹理 texel 是 inpainting 新增覆盖，不能称为直接观测纹理。
3. **外观一致性：** generated views 存在明显 cross-view source-fusion/color inconsistency；不能把低 cross-view variance 直接解释为更高 GT fidelity。
4. **导出语义限制：** `obj_0048` 有 exporter reindex/deduplication，不能作 byte-identical export 例证。
5. **GT sanity 范围不足：** GT-to-GT 仅覆盖两个 smoke objects；12-object generated batch 没有 GT condition。
6. **指标缺失：** DISTS unavailable；所有结果不得写成 DISTS 评价。
7. **总体外推限制：** cohort 后验分层且只有 12 个对象；不能外推到 276/300 个对象，也不能写 unbiased generalization。
8. **审计记录不一致：** `BAKE_12_VALIDATION_AUDIT.md` 的 `gt_to_gt_sanity_rows: 12` 叙述与当前 machine-readable summary 的 0 不一致；论文应以“正式 12-object batch 无 GT、GT smoke 为 2 objects”这一共同事实为准，不引用该字段作为 GT 证据。

## 8. 论文应避免的说法

避免以下表述：

- “TCAS/C3 提升了真实完整物体、纹理忠实度或最终 GLB 质量，并优于 fixed-low。”
- “12 个对象或 528 个视角证明了 276/300-object 的 3D 泛化优势。”
- “所有对象均有完整纹理覆盖”“texture coverage 接近 1”“inpaint 后覆盖率等于真实观测覆盖率。”
- “`uv_seam_discontinuity=0` 证明无 seam。”
- “GT-to-GT 在 12 个对象上通过”或“GT bake 验证了 generated color fidelity。”
- “GLB 导出逐顶点/字节级保持”或忽略 `obj_0048` 的 reindexing。
- “DISTS 已验证”“DISTS 缺测可按 0 处理”。
- “unseen unlit render 等价于最终 photometric 3D 渲染质量”。

可接受的保守说法是：本批次验证了一个使用原始 UV、depth visibility 和可追溯 coverage/inpainting 输出的 CPU Exact-GLB bake/unseen diagnostic path；在固定的 12-object 分层案例中，generated-source fusion 仍造成明显外观限制，未形成相对 fixed-low 的 3D 优势证据。
