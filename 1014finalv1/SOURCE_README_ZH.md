# 1014finalv1

本版本按“多视图纹理任务中的几何控制分配实证研究”组织主文，将 TCAS/C3 作为受检验的推理期干预。主要结果以竞争基线、同预算分配、实际 UV 纹理烘焙和不同条件接口为主线。方法图从 GeoTex-Adapter 与尺度/封顶控制接到六视图，并标出所选烘焙队列的 UV 烘焙和 11 个未见相机评测路径。

主文与补充材料使用项目内最新冻结稿及其证据包中的数值、图表和引用。保留了同预算原定主要检验、次要两两比较的统计层级，以及历史 276 请求槽位中未知输入替换的限定。版本不将 C3 或新的时间配置表述为普遍最优方法。

文件：

- `1014finalv1.pdf`：主文
- `Supplementary_1014finalv1.pdf`：补充材料
- `1014finalv1.tex`、`Supplementary_1014finalv1.tex`：对应源稿
- `build_1014finalv1.py`：隔离构建脚本

在当前目录运行 `python3 build_1014finalv1.py` 可重建两份 PDF。构建依赖、图表和表格文件一并保留在本目录。
