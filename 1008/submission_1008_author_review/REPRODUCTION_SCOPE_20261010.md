# Revision reproduction scope

The new bounded expansion freezes 50 previously unobserved MV-Adapter output objects and 10 previously unbaked technical objects. Their source cohort had already been evaluated in GeoTex image space; neither is represented as a wholly new image holdout. Old seven-object MV-Adapter metrics have a target-camera mismatch. Old five-object baked estimates are superseded after correcting the raw pole-view mask direction and scalar-mask decoding. REPEAT interpolation uses fractions before index wrapping. The source masks now match exactly for GT and generated inputs on all 90 source views of the five old and ten new objects.

The delivered inference scripts were executed in the recorded local environment with frozen local weights and source assets. The statistics package contains object-level rows and standalone recomputation scripts. Model weights, raw GLBs and source-image archives are not redistributed. Replaying inference requires those licensed inputs, the specified model versions and the supplied run configuration; this is not a claim of public hosting or complete historical FAC reconstruction.

GeoTex Constant 1.0 under native caps is not the unset-scale pipeline: the shallow factor is 0.8 versus 1.0. MV-Adapter native default, deployed default and constant-1 scheduling pass the new three-object pixel/residual identity gate.

No CAI derivation, optimality claim, new adaptive selector or FAC retraining is introduced. A confidence interval crossing zero is not equivalence. All outcome-valid negative results remain in the revision.
