# 第15版：结果、审稿风险与相对第14版判断

本轮保留第14版全部核心测量和推断，新增的是既有数据的描述性分析、CPU投影诊断复算及可恢复代码交付。没有新方法、模型训练、参数搜索或新增生成样本。用户再次授权“需要训练可以跑”；经核查，本轮三个优先缺口无需模型训练，而新训练也无法补回旧实验身份，所以没有为占用GPU而启动训练。

## 本轮增加了什么实质信息

1. **跨视角输入一致性有了限定、可复核的评价。** 使用原冻结UV投影实现，十对象×八条件的80个原方差值逐条完全重现。前两个输入顺序对象的统一黑色/相机灰阶控制通过；灰阶独立预期与执行值最大误差约1.0×10^-8。Late-high减Fixed Mean的共享UV方差为-0.002448，描述性对象区间[-0.003473,-0.001604]，新增探索性21对比校正p=0.041。Fixed High的平均方差更低，但烘焙LPIPS更高；因此一致性与保真必须分开。恒定错误颜色也能达到零方差。此项不验证接缝、PBR、任意资产的投影正确性或普遍质量收益。
2. **“可检测平均收益”与“逐对象稳定收益”被量化区分。** GSO100的Late--Mean PSNR三种子均值均为正（+0.0568/+0.0383/+0.0387 dB），但仅27/100对象三次同向有利，68/100方向混合或持平。非参考LPIPS的第三种子均值变号；GSO20烘焙仅1/20对象三种子均有利，14/20方向混合或持平。这不改变原总体检验，也不是对训练随机性的估计。
3. **C3与强控制的对象级比较更完整。** 270/300对象在四个已记录图像端点的点估计上被至少一个其他控制弱支配；Fixed High单独支配173对象，C3反向支配16对象。这里的90%是特定样本、控制及端点的描述性比例，不是中稿概率，也不是“90%对象纹理失败”。未测质量和每对象显著差异不在推断范围。
4. **FAC源码披露更具体。** 提供84个原字节源码/配置/依赖文件和逐文件校验清单。早期入口默认可训练基础adapter/encoder，只有特定flag才冻结；后期入口仅训练controller。两者controller文件相同，实际执行的是三个不同控制器fixture，不能把重复文件算独立验证。前向、梯度通路和状态保存加载通过；原1706对象训练清单、种子、checkpoint及完整运行身份仍缺失。FSC实际使用FFT，初始过滤也不是严格恒等；旧注释不能替代实现事实。

新增seed、支配和UV诊断均为看到此前输出之后提出的补充，不能包装成预注册确认。原对象、全部条件、三个种子及负结果完整保留。

## 与第14版比较

| 维度 | 变化 | 判断依据 |
|---|---|---|
| R1跨视角一致性 | 改善，仍有限 | 从只有展示/无已验证诊断，增加原值重放和已知颜色控制；不冒充接缝或保真 |
| R1 FAC代码 | 改善，精确重放仍未完成 | 可恢复源码、入口差别与离线组件执行已交付 |
| 应用结论的稳定性 | 解释改善，优势主张进一步收窄 | 真实多种子分布显示平均小收益不等于逐对象保证 |
| R2贡献 | 小幅增强实证内容，方法创新没有新增 | 增加关于部署重复性/一致性指标意义的量化发现；并非新调度算法 |
| 模型实际质量和竞争力 | 没有变化 | 未改变模型、输出或原主检验 |
| 可信度与审稿回应 | 改善 | 补充结论对照完整数据、反例、代码和限定范围 |
| 可读性与交付 | 以最终PDF/包核验为准 | 增量主要进Supplement；主文继续围绕强控制、应用端点和接口边界 |

这版更适合专家判断研究提供了哪些有限而有用的证据；它没有让TCAS在算法排行榜上变强。新增限制的公开呈现会使旧优势叙事更难成立，这是数据本身的含义，不能通过隐藏分析来回避。

## 审稿人可能继续攻击的点

- **R2.1：仍是首要风险。** 调度原理已有先例，编辑可能认为现有受控应用研究不足以替代方法性贡献。预算、bake、种子和源码证据增加实证分量，不能自动解决这一价值判断。
- **R1.2：旧主adapter的0.96 dB没有同checkpoint重放。** 新matched holdout有效，但不同训练权重不能叫原数字的复现。
- **R1.1：应用表现与代表性不足。** GeoTex仅十个兼容资产；另一20对象结果不支持稳定烘焙收益。UV方差只反映特定投影下的输入不一致，不能证明可用材料或消除可见失配。
- **跨骨干与域/协议混杂。** 新native MV-Adapter与保留的MVDiffusion确为不同接口，但不同权重、目标、采样和控制算子不允许归因于骨干本身。没有稳定普遍优势。
- **新增分析是后验的。** 新family及区间只作探索；不能重新定义“主要结果”来追求显著性。
- **FAC仍非历史全链重放。** 可恢复代码和组件运行不能取代完整checkpoint/训练名单/随机种子与原表的身份链。

## 中稿机会判断与下一步取舍

没有该稿的校准模型、编辑内部决策或相似修回样本，不能负责任地报一个百分比，也不能断言超过90%。若编辑认可受控、具应用意义的实证论文，本轮比第14版更容易被公平评价；若坚持必须有新方法，风险仍高。当前最合理的判断是**回应完整性继续改善，创新性拒稿风险仍显著**。

不建议继续无目的地扩大训练、增加模型或重扫参数；这些行为不能补回旧身份，也未必改变混合结果。比继续训练更有潜在价值的后续工作是针对新checkpoint真实输出的独立、盲化实用质量评价，但必须由真实受试者提供判断，不能用视觉AI评审冒充人类研究。本轮的视觉模型检查只验证展示与叙述是否对应。
