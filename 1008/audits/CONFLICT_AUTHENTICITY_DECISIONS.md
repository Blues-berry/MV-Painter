## Decision rule

Resolve the source and execution provenance first. Prefer the version that is
more reproducible and supports narrower, better-audited claims. A source file
or clean Git merge alone does not establish that an experiment was run with
that version. Historical candidate files are kept in dated, source-pinned
archives and are not active code or paper authority.

## Resolved choices

### Manuscript source: 01549 submission

The submitted `latex.zip`, its `final_0903.tex`, and the 15-page submitted PDF
were authenticated by SHA-256 and a clean rebuild. The rebuilt PDF rasterized
identically on all 15 pages. The exact hashes and method are recorded in
`01549_SOURCE_BASELINE_VERIFICATION.md`. The root `final/final_0903.tex`, d59's
restructured manuscript, and the 2026-09-29/10-01/10-06 manuscript candidates
are not substitutes for this source. No manuscript edit is made in this phase.

### Evaluation/runtime code: d59 over the 2026-09-29 branches

The conflicting runner versions on `origin/codex/round2-author-review-20260929`
and `origin/codex/adaptive-control-pilot-20260929` remove Python/NumPy and
per-object random seeding from the evaluation paths, remove support for
conditions generated by the handoff, and drop GPU-node diagnostics. The d59
versions retain these controls and diagnostics, so they are the stronger
reproducibility and compatibility source. This source comparison does not
prove which code produced every historical output; outputs without a
run-to-source identity remain unpromoted. The old runner files are retained
under the two dated `source_conflicts/` archives for comparison only.

### Scientific validation v3: 2026-10-06 source over 2026-10-03 source

The local 2026-10-06 v3 source (`5c2c8829a1e19b42837761160dc4c14cf8f09045`)
is preferred to public `origin/codex/scientific-validation-v3-20261002`
(`11cffe795673f62ac1921fb9f0221fbdc88130ae`) for the six conflicting paths.
The later analysis adds fallback row identities, searches across campaigns,
uses the plus-one bootstrap correction and the stated Holm family, and handles
the favorable direction correctly for lower-is-better LPIPS. Its ground-truth
manifest builder checks official-order six-view coverage. The later claim
matrix reflects post-campaign evidence. These are source-level improvements;
they do not by themselves authenticate all execution outputs.

The later v3 manifest also explicitly records the missing `g_0062` mesh as a
pre-generation loader failure, does not replace it, and uses 99 as the G
denominator. The later `g_0098` technical failure is separately recorded,
leaving the reported comparison at 98/99. The design was frozen before the G
run, and the denominator change is documented in the October 4 manifest
update. This supports treating the exclusion as a documented technical
failure rather than outcome-based replacement. The retained v3 claim ceiling
still governs what can be stated; no cohorts are pooled.

## Human-study boundary

The 1006 confirmatory label is not accepted as current paper evidence. The
available audit reports 0/40 assignments matching the frozen schedule, lacks
independent records for randomization seed, question order, and stimulus-hash
crosswalk, and describes a classification override. There were 37 valid
respondents and eight endpoints; none survives the reported Holm correction.
The current manuscript scope therefore omits these results. Candidate
human-study files are preserved only in the private archive, not the public
candidate. Existing public-history participant-level files are not rewritten
by this work.
