# Fresh C LLH and linear comparison addendum

**Status:** Frozen before any Fresh C model output.  This is a revision-era,
prospective comparison on a new cohort; it was motivated by previously seen
Fresh B/C results and is not part of the original preregistration.

The companion JSON file is the machine-enforced lock: it pins this text, the
original Fresh C protocol and candidate queue, the runner/checkpoint/config,
and the launch/audit scripts.

## Scope and separation from the primary confirmation

The original Fresh C protocol remains unchanged: its four conditions are
`no_adapter`, `native_gfl`, `native_gfh`, and `native_gc3`; its only primary
test is `native_gc3 − native_gfl` on FG-PSNR.  This addendum adds only
`layer_llh` and endpoint-matched `gen_linear` in the independent output
namespace `runs/revision_era_addendum/`.  It does not change the cohort,
object order, seed, checkpoint, configuration, runner, metrics, or native-cap
semantics.  The new methods use the exact same frozen Fresh C UID list and
rendered inputs as the primary run.

No output-dependent inclusion, replacement, stopping, schedule adjustment, or
condition change is permitted.  A primary-run integrity PASS is a technical
launch dependency only; whether its estimated treatment effect is positive,
null, or negative does not affect execution of this addendum.  Both conditions
must be run for every frozen object, including after a failure in one method;
failures are retained and block analysis rather than trigger replacement.

## Frozen comparisons and multiplicity

The three named contrasts use condition A minus condition B:

1. `layer_llh − native_gc3` (LLH − C3)
2. `layer_llh − gen_linear` (LLH − linear)
3. `native_gc3 − gen_linear` (C3 − linear)

The primary endpoint family contains FG-PSNR and FG-LPIPS for all three
contrasts (six two-sided paired tests), adjusted together with Holm's method.
The five remaining Core-7 endpoints (FG-SSIM, Edge-SSIM, Full-PSNR,
Full-LPIPS, Full-SSIM) form a separate 15-test Holm family across the same
three contrasts.  For every contrast and endpoint, report the paired mean and
median, 95% percentile object-bootstrap interval (10,000 draws; seed
20261007), two-sided paired t-test, and direction-adjusted favorable-object
fraction.  Object is the inferential unit.  Views, pixels, denoising steps,
and repeated seeds are not independent observations.  FG-PSNR is
higher-is-better; LPIPS is lower-is-better.  No equivalence or
non-inferiority claim is allowed because no such margin was frozen.

The six-test primary family has the following interpretations: a corrected
test plus an interval excluding zero supports only that named endpoint and
contrast on this cohort; a non-significant result is inconclusive, not
equivalence.  A significant result in one endpoint does not establish a
joint quality winner when the other endpoint disagrees.  The C3−GFL primary
test remains separate and retains the interpretation in the original Fresh C
protocol.
