# 修订证据归档（非人工范围）

本目录汇总截至 2026-10-07 的 C&G 修订非人工实验结果、审计结论和审稿意见映射。这里是本地证据归档，不是公开发布包。

## 读取顺序

1. `CANONICAL_RESULTS.md`：各轮实验的唯一采用结果和使用边界。
2. `EVIDENCE_REVIEWER_MATRIX.md`：上传审稿意见逐条对应到证据状态和剩余主张边界。
3. `MASTER_LOG.md`：审计过程、文件来源、版本冲突和本次整理记录。
4. `RESULT_STATUS_LEDGER.csv`：机器可筛选的实验/审计状态表。
5. `ARTIFACT_MANIFEST.csv` 和 `SHA256SUMS.txt`：源文件与归档副本的校验记录。
6. `source/`：被选入的原始审计报告、汇总结果和图件副本。

## 归档边界

- 本轮没有修改 01549 主稿、没有追加实验、没有运行新的模型推理，也没有提交或推送。
- 人工实验的重新设计、招募、答卷、答卷分析和结果解释均不在本归档范围内；相关材料未复制。审稿意见原文仅作为映射来源保存。
- GLB 原始资产、逐对象 UID 指标表、渲染输入与逐对象生成文件保留在原位置，本归档只收录允许复核的汇总结果。
- 图集接触页随附逐项 CC BY attribution；即便如此，本目录仍不能直接视作公开发布包。当前提交候选的干净检出重建门禁未通过。
- `source/` 中选入的原始报告为逐字副本；另有一个针对混合范围 GLB 报告的非人工指标摘录，均在 manifest 中标明。报告内的相对链接仍指向仓库原始位置。原始文件没有移动或覆盖。
