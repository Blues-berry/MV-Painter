# 中稿风险与不跑新实验的完善空间

## 判断

目前应按“仍有实质机会，但拒稿风险偏高”准备，不能按接近接收处理。没有编辑的最新决定、相似修回案例的可靠基准或审稿人对本轮新增证据的反馈，无法给出可信的中稿百分比。论文指标的置信区间不是中稿概率；三名审稿人的态度也不能换算为投票概率。

相对01549，这轮提高了证据可信度，补足有效第二骨干检验并提供真实烘焙，但同时撤掉了C3普遍优势和CAI独立推导。可信度提高不等于接收可能性必然提高：编辑仍需判断重新定位后的实证贡献是否足够。

C&G官方范围覆盖计算机图形学研究和应用，并不限于新算法，这给受控系统实证研究留下空间；但期刊范围本身不能证明本稿的贡献达到标准。来源：Elsevier官方期刊页面 https://shop.elsevier.com/journals/computers-and-graphics/0097-8493 。以下风险判断主要依据本地审稿原文和当前结果，不是期刊公开接收率模型。

## 决定性因素

| 因素 | 本轮变化 | 对判断的影响 |
|---|---|---|
| R3已认可 | 没有新增技术要求 | 有利背景，不能约束编辑或另两位审稿人 |
| R2.3第二骨干 | 从N7失效质量评价推进到有效native50 | 明显缩小实验缺口，但主比较未分离、接口不同 |
| R2.2 CAI | 撤掉推导和最优性 | 可解决形式化包装问题，同时削弱旧理论贡献 |
| R2.1创新性 | 重新定位为受控阶段分配、烘焙及边界发现 | 仍是最大的拒稿风险；没有新一般算法 |
| R1.1实际质量 | 完整对象、GT、未见视角与视频改善 | 相似棕色纹理失败、真默认缺失、接缝/PBR未验证仍限制实用性 |
| R1.2原主adapter留出 | 新checkpoint配对证据有效 | 原+0.96未直接复现，只能部分回应 |
| R1.5 FAC | 清楚交付可复算部分 | 原训练记录缺口不能靠说明消除 |

若编辑与R2接受“具有明确图形学意义的受控实证研究”这一定位，native50和bake10可支持继续修回或接收讨论。若仍要求具有新算法贡献，或R1把当前外观失败判为基础管线无效，则仅靠这轮文字与版式无法挽回。这两种路径不能用现有信息赋予可靠数值概率。

## 本轮已完成的不跑实验完善

1. 主文限制从重复的档案审计收紧为四个科学限制段；原详细记录完整移入Supplement S19，不删除不利证据。
2. 摘要突出实际研究问题、三个证据集与持续外观失败，不再把撤回历史推导当作摘要贡献。
3. 结论减少历史队列的重复数值，集中解释matched300、bake10和native50，不恢复最优性或可部署主张。
4. 审稿回复新增逐项完成度表：给出已有证据与实际缺口，方便编辑区分已解决与部分解决。
5. R2.1回复以具体受控发现解释实证价值，避免仅以“由编辑判断”结束创新性回应。
6. 保留先前图文、强基线、GT校准、队列身份、原主比较、负结果、来源署名和代码交付修订。
