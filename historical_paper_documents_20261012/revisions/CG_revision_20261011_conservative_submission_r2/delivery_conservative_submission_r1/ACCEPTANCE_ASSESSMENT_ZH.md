# 保守提交版 r1 的审稿风险评估

无法从现有材料可信地给出具体中稿百分比。缺少编辑最新决定、对本轮回复的反应和可比修回样本，不能把结果指标的置信区间换算成接收概率。对照 01549，r1 提高了可审计性、图文一致性和回复完整度，但这不等于创新性争议已消失。

现在最有支撑的部分是：训练时无需新增参数的显式控制定义；原盲评刺激上的总体偏好；Fresh C 中 C3 相对 Fixed Low 的配对 FG-PSNR 结果；严格区分强固定/线性基线、等预算分配及端点排序；GT-256 校准的十对象烘焙比较；以及有效的 native MV-Adapter N=50 矩阵。历史 +0.96 dB 只作为原 checkpoint、原 pooled full-image PSNR 的历史结果，不当作 Fresh C 的复现。

最大风险仍是 R2.1：调度思想已有相关先例，论文没有新的通用调度算法；稿件需要说服编辑，任务内的受控图形学实证和已有偏好/下游验证足以构成贡献。第二大风险是 R1.1 的应用价值：烘焙指标有小幅相对变化，但兼容集只有十个对象，真实输出仍出现外观偏差；真正的 GeoTex 默认 unset-scale、seam 指标及 PBR/重光照评价未完成。R1.2 对原主 checkpoint 的直接留出复现和 R1.5 FAC 全量复现也仍受历史记录缺口限制。R2.3 从失效 N=7 推进到有效 N=50，但其冻结主比较区间包括零，接口和目标也不同。

本轮不跑新实验也能完成的主要事项已经落地：正文聚焦、历史与新队列拆开、指标评价范围写清、图源/裁剪/署名核验、完整配对差值可视化、seed 来源关联、审稿意见定位校准、响应 PDF 版本修复、提交件和独立重建。继续纯文字打磨可以降低误读，不能补出原 checkpoint 复现、默认管线结果、FAC 权重或更强的算法新颖性证据。

因此应按“修回质量明显提高，仍有较高拒稿风险”准备，而不是“稳中”。如果编辑接受受控系统实证定位，明确证据边界会有帮助；如果编辑要求新方法或可见的通用纹理质量改善，当前证据不能保证满足。
