# C&G 保守修订版 r2：审稿接受风险评估

r2 比 r1 多提供了完整、可复算的一条 64 对象随访证据链，并把它与 TCAS/C3 分开。这加强了修回的证据管理和 R2.1 回复的具体性，但没有改变 TCAS 的主结果、主要图表或方法贡献，因此接受机会不宜因此上调很多。

## 仍有说服力的部分

- Fresh C 是独立 checkpoint 下的 300 对象配对评估，具名 Fixed Low 比较为 +0.522 dB foreground FG-PSNR，并有对象级区间；强固定/线性基线和等预算分析在主文中可见。
- 偏好证据、真实输出、十对象烘焙与 MV-Adapter 原生 N=50 评价使稿件不再只有单一图像指标。正文区分历史 pooled +0.96 dB 与 Fresh C +0.522 dB，且不从历史汇总值补造区间。
- S22 的两项源视角 projection 结果经保存评分行复算；它为独立的几何条件 CFG 交互问题提供了明确发现，并有相邻强基线比较。

## 仍然限制接受的核心因素

- R2.1 仍是主要拒稿风险：时间/层调度和几何强度控制已有先例，C3 仍是历史开发选型；新 S22 是另一种干预，不能证明 TCAS/C3 的新颖性或修复其算法贡献。
- MV-Adapter N=50 的冻结主要比较区间含零，只能证明做过有效的第二接口测试，不能声称跨骨干效果稳定复现。
- S22 64 对象队列排除了该 projection 方法自己的 32 对象开发集，但曾进入历史 Fresh C 研究；源视角改善不代表非参考视角、烘焙外观或纹理保真。未给非劣效界。
- R1.1 的默认管线身份、接缝、PBR/重光照、FAC 训练恢复仍有限；十对象烘焙改善是具名指标比较，视觉上仍能看到明显外观差异。

## 综合判断

相对 r1，r2 提升了 R2.1 回复的信息量和证据可审计性，也能减少“新增支线没有报告清楚”的风险；它没有提供一项直接证明 TCAS/C3 新颖或跨架构成功的结果。因此这仍是**有竞争力但偏高风险的修回稿**，不应描述为“已解决创新性问题”或“中稿把握大”。在没有期刊决策模型、编辑偏好样本和对照稿件数据的情况下，给出精确百分比会是假精确；若必须做区间式判断，r2 只能算较 r1 略有改善，仍处在低到中等接受把握，而非中高把握。

最有价值的非实验完善已经落实在口径、配对统计、完整图示、回复映射和独立重建上。继续删掉有效反例或把 S22 合并成 TCAS 证据会增加可信度风险；GSO100/APG/bake 后续若得到结果，应先独立核对队列、端点、错误和多重性，再决定是否另起版本。
